# Projeto Só Fluxo - MVP de Gestão Financeira

## Descrição
O *Só Fluxo* é um aplicativo web voltado para MEIs e freelancers, focado em transformar a gestão financeira passiva em uma análise ativa com base na metodologia de controle orçamentário 50/30/20.

## Funcionalidades do MVP
- *Motor de Categorização Estrita:* Divisão automática de gastos em Essencial, Lanches/Lazer e Dívidas.
- *Analista Pessoal Proativo:* Alertas visuais e avisos quando o usuário extrapola os limites recomendados de lazer.
- *Dashboard Comparativo:* Comparação visual entre o orçamento planejado e o realizado.

## Tecnologias Utilizadas
- HTML5, CSS3 e JavaScript.
