Sobre o Projeto

O Só Fluxo é uma ferramenta de gestão financeira projetada especificamente para MEIs e freelancers, automatizando o controle de entradas e saídas com alertas proativos para manter a saúde financeira organizada.

Funcionalidades do Projeto:

  • Divisão automática de orçamento (Metodologia 50/30/20).
  • Dashboard interativo para acompanhamento de fluxo de caixa.
  • Alertas inteligentes para controle de despesas e lucros.
